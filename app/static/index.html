O que foi medido?
Os dados de cada passo vêm da mesma execução que escolheu o token de saída. Hooks capturam a saída de seis blocos decoder, na última posição processada. Dividimos os canais em até 16 grupos contíguos e calculamos RMS = √(média dos quadrados). A cor e o tamanho usam a maior medida de grupo de toda a captura recebida até o momento. A escala pode aumentar enquanto chegam novos passos.
A primeira captura processa o prompt inteiro; as seguintes processam um token com cache KV. Em cada passo, a posição processada prediz o próximo token: não confunda os valores capturados com ativações desse token ainda não processado. A matriz de atenção selecionada corresponde à última consulta desse passo e inclui tokens de sistema e marcadores do chat.
As posições 3D são esquemáticas; não desenhamos pesos de conexões. A numeração e os valores das camadas são reais. A rotação é decorativa. Think produz tokens adicionais pelo mesmo modelo. O texto é exibido como decodificado, incluindo marcadores de thinking que o tokenizer preserve.
